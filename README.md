# ATM Management System (Python)

## Overview

This is a simple ATM Management System developed using Python. The program simulates basic ATM operations such as PIN authentication, balance inquiry, cash withdrawal, and cash deposit through a menu-driven interface.

The project demonstrates fundamental Python programming concepts including functions, loops, conditional statements, user input handling, and basic banking operations.

---

## Features

* Secure PIN authentication
* Maximum 3 login attempts
* Check account balance
* Withdraw money
* Deposit money
* Exit from ATM menu
* Account lock after multiple invalid PIN attempts

## How It Works

### 1. PIN Verification

* User enters a PIN.
* If the PIN is correct, access to the ATM menu is granted.
* User gets a maximum of 3 attempts.
* After 3 incorrect attempts, the account is locked.

### 2. ATM Menu

The following options are available:

1. Check Balance
2. Withdraw Money
3. Deposit Money
4. Exit
